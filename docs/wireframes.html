출발시각 와이어프레임

목적지와 도착 시각을 넣으면 집에서 나설 시각을 알려주는 앱의 전체 흐름입니다. 시간 감각이 약하고 나서기 시작하기 어려운 사람, 특히 ADHD가 있는 사람이 실제로 제시간에 현관을 나서도록 돕는 데 초점을 둡니다.

M3화면마다 붙은 번호를 적어 댓글로 추가·수정할 점을 남겨주세요. 예시 시각과 경로는 설명용입니다.

원칙

  • 매일 같은 곳을 오가는 사람이 대상입니다. 길 찾기와 노선도는 두지 않습니다.
  • 설정할 것은 최소한으로 둡니다. 한 번 저장하면 돌아오는 길까지 자동으로 생깁니다.

만드는 순서

1차첫 설정, 홈, 목적지와 경로, 알림 두 번, 잠금화면 이동 표시, 출발·역 도착·목적지 도착 기록, 늦었을 때, 돌아오는 길, 막차 카드와 알림, 경로별 오차와 늦은 이유
2차다이내믹 아일랜드 상태별 표시, 지각 알리기, 반복 제안, 통계 T1~T2, 출발 시각 최적화와 홈의 절벽 경고, 붐비는 시간대, 실시간 지연 푸시 서버
3차움직임 분석 T3~T4, 막차를 놓쳤을 때

정해진 것

  • 서울 지하철에서 지하철까지만 다룹니다. 버스는 이번 범위에서 뺍니다.
  • 계산은 목적지 역 도착까지입니다. 역에서 최종 목적지까지 걷는 시간은 선택 입력으로 받고, 도착 감지가 켜져 있으면 실측값으로 바뀝니다.
  • 경로는 최단시간과 최소환승 두 가지를 보여줍니다. 둘이 같은 경로면 하나만 보여줍니다.
  • 홈은 다음 일정 하나를 크게 보여줍니다. 일정이 없는 날은 "어디 가요?" 버튼 하나만 둡니다.
  • 사용자가 직접 누르는 건 출발 버튼 하나뿐입니다. 역 도착, 목적지 도착, 대기 시간 분석은 자동으로 기록하고, 자동 감지를 끈 사람만 "승강장 도착" 버튼을 씁니다.
  • 준비 시간은 묻지도 재지도 않습니다. 한 번 이동할 때 알림은 미리 알림과 나갈 시각 두 번뿐입니다. 미리 알림은 기본 10분 전이고 설정에서 바꿉니다. 막차도 같은 규칙으로 두 번 울립니다.
  • 목적지 역 출구와 최종 도착지도 자동으로 감지합니다. 목적지 쪽 도보 시간과 개인 걸음 속도를 배우는 데 쓰고, 새 설정 항목은 만들지 않습니다.
  • 첫 설정에서 집 위치를 한 번 받아 가까운 역과 걷는 시간을 제안합니다. 위치 권한은 여기서 시작해 도착 감지까지 자연스럽게 이어갑니다.
  • 위치 기록은 폰에만 저장하고 서버로 보내지 않습니다.
  • 급행과 일반은 앱이 도착 시각 기준으로 고릅니다. 목적지가 일반 정차역이면 급행을 타다 일반으로 갈아타는 것까지 안내합니다.
  • 필요한 정보는 필요한 순간에만 묻습니다. 반복 요일은 묻지 않고 같은 곳에 세 번째 도착하면 제안하고, 목적지 이름은 역 이름으로 자동으로 붙입니다.
  • 공휴일은 묻지 않고 달력 데이터로 처리합니다. 휴일 시간표를 쓰고 평일 알림은 쉽니다.
  • 연차나 재택처럼 안 가는 날은 알림이나 홈에서 "오늘은 안 가요" 한 번으로 그날만 끕니다.
  • 입력한 시각이 곧 도착 목표입니다. 일찍 도착 여유는 기본 0분이고 원하는 사람만 설정에서 켭니다. 켜면 결과 화면에 드러내 보여줍니다. 사람들이 이미 여유를 넣어 시각을 적는 경우가 많아 기본값에서 뺐습니다.
  • 환승마다 필요한 여유를 따로 계산합니다. 표준 환승 시간(경로 API와 서울교통공사 환승 거리 중 긴 쪽) × 내 걸음 배율 + 기본 여유(같은 승강장 30초, 그 외 최소 1분, 긴 환승일수록 더, 출퇴근 시간 +30초). 대기 시간이 모자란 연결은 고르지 않습니다.
  • 빠른 칸을 안내합니다. "4-4칸 타면 환승 가까워요"처럼 탈 칸을 알려줍니다. 서울교통공사 환승 데이터에 없는 역은 표시하지 않습니다.
  • 돌아오는 길은 오늘 가는 길 기록이 있을 때만, 목적지 도착 뒤 홈에 띄웁니다.
  • 지각이 확실하면 늦는다고 알릴 문장을 만들어 줍니다. 사실만 쓰고, 보내는 건 사용자가 합니다.
  • 출발지는 집, 저장한 곳, 지금 있는 곳 중에서 고릅니다. 지금 위치에 맞춰 자동으로 골라둡니다.
  • "어디 가요?"를 누르면 최근 간 역을 먼저 보여줍니다. 약속 장소처럼 반복은 안 해도 다시 가는 곳을 위해서입니다.
  • 집이 아닌 곳에 있고 막차까지 2시간 안쪽이 되면 막차 기준으로 일어날 시각을 알려줍니다. 막차 묶음 L1~L4 참고.
  • 통계로 정시 도착과 현관 정시 출발을 달력과 추세로 보여줍니다. 통계 묶음 T1~T4 참고.
  • 움직임 센서로 걷기와 멈춤을 나눠 엘리베이터·신호 대기를 자동으로 분석합니다. 도어 투 도어 시간과 출퇴근 걸음 수도 자동으로 기록합니다.
  • 경로마다 출발 시각별 도착표를 만들어, 손해 보는 출발 시각을 거르고 추천 출발 시각과 "놓치면 크게 늦어지는 열차"를 알려줍니다.
  • 출발 시각이 매일 다른 사람을 위해 마감 없는 날, 오늘만 다른 날, 습관 보정을 따로 다룹니다.
  • 경로와 시간대별로 예상보다 얼마나 늦게 도착하는지 배워서 여유에 자동으로 더합니다.
  • 평소보다 늦게 도착하면 이유를 먼저 스스로 추정하고, 애매할 때만 한 번 묻습니다. 모인 이유로 붐비는 시간대를 표시합니다.
  • 현관 체크리스트는 나중으로 미룹니다.
  • 경로는 서울 열린데이터광장의 서울교통공사 최단경로 API를 씁니다. 이미 가진 키로 동작하고, 9호선 급행과 신분당선, 환승 도보 시간까지 나옵니다.

알림과 감지 켜기 · 권장
알림만 켜기
  • 새로O2에서 받은 "앱 사용 중" 위치 권한을 여기서 "항상 허용"으로 올려달라고 요청합니다. 알림 허용도 같은 화면에서 받습니다. 위치는 "항상 허용"이 필요해서 권장하되 건너뛸 수 있게 하고, 끄면 이동 중 화면에 "승강장 도착" 버튼이 대신 나옵니다.
  • ADHD준비 시간은 묻지 않습니다. 알림은 미리 한 번, 나갈 때 한 번만 보냅니다.
  • 새로목적지 쪽도 같은 권한으로 감지합니다. 회사 주소는 묻지 않고, 역에서 나와 매번 머무는 곳을 도착지로 추정합니다.
