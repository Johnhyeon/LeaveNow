# 출발시각 v2 로드맵

목적지와 도착 시각을 넣으면 집에서 나설 시각을 알려주는 앱. 화면 설계는 [wireframes.html](wireframes.html)에 있고, 화면 번호(O1, M3 등)는 그 문서를 따른다.

## 진행 원칙

- 단계마다 폰에 설치해서 다음 날 출근길에 바로 써볼 수 있는 상태로 끝낸다.
- 설계를 뒤집을 수 있는 기술 위험은 먼저 작은 시험 코드로 확인한다.
- v1 코드 중 실시간 도착(`RealtimeService`), 알림(`NotificationManager`), API 키(`Secrets`), 설치 스크립트는 가져가고, 여섯 구간 측정 화면과 역별 시간표 저장소는 걷어낸다.
- v1 측정 기록은 버리지 않고 "집에서 승강장까지" 한 구간으로 합쳐 옮긴다.
- 작업 브랜치는 `v2`.

## 데이터 출처 (모두 서울 열린데이터광장, 기존 키로 동작 확인)

| 용도 | API | 비고 |
|---|---|---|
| 경로, 열차 시각, 환승 도보 | `getShtrmPath` | 최소시간·최소환승, 9호선 급행·신분당선 포함, 응답 약 0.2초. 도착 시각 기준 검색은 없어 출발 시각을 바꿔가며 조회 |
| 역 목록과 좌표 | `subwayStationMaster` | 수도권 784개 역, 역 ID가 경로 API와 같은 체계 |
| 실시간 도착 | `realtimeStationArrival` | v1에서 사용 중 |
| 혼잡도 통계 | 서울교통공사 지하철혼잡도정보 | 분기별 파일, 30분 단위, 2차에서 사용 |

1차를 마치면 1~2주 그대로 써서 예측과 실제를 비교한다.
