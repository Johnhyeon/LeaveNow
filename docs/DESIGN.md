# 출발시각 디자인 규칙

선택한 방향: **3안, 평소엔 물 화면, 올리면 노선도** ([시안 비교](design-directions.html)의 E×G 3안).
코드 기준은 `LeaveNow/Design/`이고, 색과 글꼴은 `Theme.swift` 한 곳에서만 정한다.

## 원칙

- 화면에서 가장 큰 것은 언제나 **남은 시간 숫자**다.
- 남은 시간은 숫자와 **물 높이** 두 가지로 보여준다. 숫자를 읽기 전에 물 높이로 먼저 느낀다.
- 처음 보이는 건 물과 숫자뿐이다. 여정은 아래 시트에 한 줄로만 보이고, 올려야 노선도가 펼쳐진다.
- 여정은 지하철 노선도처럼 그린다. 간격은 실제 걸리는 시간에 비례한다.
- 기본 부품(시트, 버튼, 알림)은 iOS 기본 모양을 그대로 쓴다.

## 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| paper | `#EEF3F9` | 아침 바탕 |
| nightPaper | `#0B1020` | 밤·막차 바탕 |
| sheet / nightSheet | `#F7F9FC` / `#141B2E` | 아래 시트 |
| ink / mute | `#0F1724` / `#5E6C7F` | 글자, 보조 글자 |
| dayWater | `#5AA7FF` → `#2F7BF0` | 평소 물 |
| urgentWater | `#FFA25C` → `#F2711C` | 남은 시간 5분 안쪽 |
| nightWater | `#2CC0B2` → `#138C84` | 막차 |
| now / nightNow | `#0A6CFF` / `#FFB23E` | 노선도의 '지금' 점 |
| walk | `#A7B1BE` | 걷는 구간 점선 |

노선색은 서울 지하철 공식 색을 그대로 쓴다. 예: 9호선 `#BDB092`, 2호선 `#00A84D`, 신분당선 `#D4003B`.

## 글꼴

- 큰 숫자: SF Pro Rounded, 가장 굵게(Black), 숫자 폭 고정. `Theme.number(size)`.
- 홈 숫자 150pt, 시트를 올렸을 때 64pt, 잠금화면 56pt, 펼친 아일랜드 44pt.
- 나머지 글자는 시스템 글꼴 기본 크기 체계를 따른다. 동적 글자 크기를 막지 않는다.

## 부품

| 부품 | 파일 | 규칙 |
|---|---|---|
| 물 | `WaterView.swift` `WaterScene` | 물 높이 = 남은 시간 ÷ 기준 시간. 물결 두 겹이 천천히 출렁인다. 동작 줄이기가 켜지면 멈춘다 |
| 물 위 글자 | `WaterScene` | 글자를 두 겹으로 그려 물에 잠긴 부분은 흰색, 물 밖은 짙은 색. 물이 빠지면 숫자가 드러난다 |
| 노선도 | `RouteViews.swift` `RouteMapView` | 세로. 열차 구간은 노선색 실선, 걷기·기다림은 회색 점선. 간격은 분 × 2.6pt, 최소 30pt |
| 한 줄 노선 | `RouteViews.swift` `RouteStripView` | 시트가 접혔을 때. 가로 비율이 시간에 비례 |
| 시트 | `WaterHomeView.swift` | 접힘 128pt, 펼침은 화면 전체. 접힌 상태에서도 뒤 화면을 만질 수 있다 |

## 물의 기준 시간

- 출발 전: 미리 알림 시각부터 현관 시각까지. 기본 20분.
- 막차: 60분.
- 남은 시간이 5분 안쪽이면 물이 주황으로 바뀐다. 빨강은 쓰지 않는다. 불안을 키우지 않기 위해서다.

## 잠금화면과 다이내믹 아일랜드

앱이 꺼져 있어도 시스템이 알아서 줄여주는 부품만 쓴다. 그래서 물결 움직임 대신 다음처럼 표현한다.

- 잠금화면: 짙은 카드에 남은 시간 숫자(56pt)와 파란 **물 막대**. 막대는 `ProgressView(timerInterval:)`라 저절로 줄어든다.
- 아일랜드 접힘: 왼쪽 작은 원형 **물통**(원형 진행 표시), 오른쪽 남은 시간.
- 아일랜드 펼침: 단계 이름, 탈 열차, 큰 숫자, 물 막대.

## 아직 정하지 않은 것

- 앱 아이콘
- 첫 설정 화면들의 모양 (1단계에서 이 규칙으로 그린다)
- 다크 모드에서 아침 화면을 밤 색으로 바꿀지
